# 种群的“J”形和“S”形增长

**一生儿 高中生物一本通** · 选择性必修 2《生物与环境》交互教学模型。

## 使用方法

下载仓库后，直接用浏览器打开 `index.html`。页面为单文件网页，无需安装依赖或联网加载资源。也可以将 `index.html` 放入静态网站目录使用。

## 功能

- J 形与 S 形增长曲线动态比较，支持播放、暂停、重播和时间轴定位。
- 调节初始数量 N₀、理想增长倍数 λ、环境容纳量 K。
- 切换种群数量、增长速率与增长率图；定位 K/2 和接近 K 的阶段。
- 两种增长方式的知识比较、概念辨析和互动判断题。
- 适配桌面与手机浏览器。

## 模型说明

J 形采用 `N(t) = N₀ λᵗ` 的连续时间延拓。S 形采用逻辑斯谛模型近似描述增长趋势。增长速率图表示当前曲线斜率，增长率按下一单位时间的相对增量计算。

数值仅用于教学示意，不代表某一物种的实际观测。详细假设和适用边界见页面底部“模型说明”。
